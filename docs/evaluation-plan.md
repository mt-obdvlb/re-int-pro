# 评测、数据与预算

2026-09-08：实现脚本与冻结数据已交付；正式百炼六策略主实验仍未执行。离线FakeLLM结果仅说明程序/统计管线可运行。

## 数据与公平比较

真实本地服务捕获：6份演示快照，80份benchmark（20开发、60测试）。开发集四故障各4、normal/unknown各2；测试四故障各12、normal/unknown各6。控制器每例48请求，注入真值在.runtime/evaluator/truth.jsonl，Agent不接收标签。快照只含公开合成业务观测。

开发和测试使用不同种子、不同严重程度区间，但同一生成器结构；manifest的family字段目前只是split名称，不能据此声称模板隔离或强OOD。缓存延迟为应用层等待；unknown样例有意缺失观测。测试集规模小、故障族简单，限制生产外推。采集/冻结命令见 [复现](../data/README.md)。

六策略 competitive_cost/no_cost/random_probe/fixed/react/graph_greedy，共享快照、工具、模型、上限和证据验证器。成本仅用开发集校准并冻结。config_hash包含快照、seed、模型、提示、策略和价格版本。修改算法后新开批次，不覆盖旧结果。模型temperature=0仍不保证确定性；完整主实验按任务×六策略×三次=1080运行。

## 指标和统计实现

run.py逐行输出实际终态、停止原因、正确性、是否定位、tokens/探测数/金额/耗时及config_hash；失败留行，不删失败重跑成成功。summarize.py拒绝重复trial、混合模型/模式、非矩形配对和同任务快照漂移；报告已知故障准确率、负例误定位、系统失败、平均探测数、总金额、p50/p95延迟，以及任务级配对bootstrap 10000次区间。重复先在任务内汇总，不能当独立样本扩大n。

当前尚未自动汇总全部候选覆盖率、预测准确性及D与实际排除数相关性；可从不可变候选/决策/证据事件复核，正式机制主张前必须补齐分析，避免只看最后定位率。不因软件可运行就认为研究证明已完成。
